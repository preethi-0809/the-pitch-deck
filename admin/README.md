# Admin & Content Management Guide

The Admin module allows administrators to:
1. **Manage Content**: Create official questions, study notes, and syllabus topics.
2. **Inspect Candidate Metrics**: View registered candidate profiles, schedule categories, and completion rates.
3. **Current Affairs Ingestion**: Add verified notifications with official citations and syllabus tags.
